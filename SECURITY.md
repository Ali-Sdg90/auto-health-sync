# Security Policy

## Supported versions

Security fixes are provided for the latest release only.

## Reporting a vulnerability

Please report vulnerabilities privately to [ali.sdg.dev90@gmail.com](mailto:ali.sdg.dev90@gmail.com) instead of opening a public issue.

Include the affected app version, impact, and minimal reproduction steps. Never send real health data, Google Drive files, access tokens, signing keys, or other credentials.
